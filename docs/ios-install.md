Test build of the Repeater Nation Radio iPhone app.

## Install it free from a Windows PC (Sideloadly)

The app has to be reinstalled every 7 days (an Apple rule for apps installed without a paid developer account).

1. Install **iTunes** from apple.com (the download from Apple's website, not the Microsoft Store one), then install **Sideloadly** from sideloadly.io.
2. On the PC, download **Repeater-Nation-Radio-x.y.z-unsigned.ipa** from the files below.
3. Plug the iPhone into the PC with a cable and tap **Trust** on the phone.
4. Open Sideloadly, drag the .ipa file into it, type your Apple ID email, and click **Start**. Enter your Apple password and code when it asks.
5. On the iPhone, open Settings, then General, then VPN & Device Management, tap your Apple ID, and tap **Trust**.
6. If the app still won't open, go to Settings, then Privacy & Security, turn on **Developer Mode**, and let the phone restart.

To reinstall every 7 days, plug the phone in and click Start in Sideloadly again. Sideloadly isn't made by Apple, so you might want to use a spare Apple ID with it.

## TestFlight (no 7-day limit)

This needs an Apple Developer account ($99 a year). Once the account's API key is added to GitHub, every build is uploaded to TestFlight automatically.
